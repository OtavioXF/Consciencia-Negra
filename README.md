# Caminhos da Consciência Negra

Um jogo de tabuleiro educativo sobre a história, a cultura e as contribuições da população negra no Brasil. Pode ser jogado individualmente ou em grupo, com até cinco participantes.

A cada partida, as 40 casas são distribuídas novamente pelo percurso. Há perguntas, bônus, penalidades, desafios, puzzles, curiosidades, casas neutras e personalidades históricas. As perguntas e atividades variam para deixar cada partida diferente.

O mapa mostra uma estrada vertical com câmera que acompanha o jogador. Também é possível explorar o percurso manualmente. O jogo apresenta fotos e imagens relacionadas aos temas e às personalidades, com uma área de créditos para consultar as fontes.

Para jogar, abra o arquivo HTML em um navegador. Não é necessário instalar o jogo.
